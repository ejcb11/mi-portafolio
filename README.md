# ⚡ Eduardo Contreras — Creative Frontend & Full Stack Developer

Portafolio profesional interactivo de desarrollo web y móvil de alto rendimiento. Construido con una estética moderna de alto contraste, tipografía brutalista y experiencias interactivas en 3D.

🌐 **Demo en vivo:** [https://mi-portafolio-eight-lyart.vercel.app](https://mi-portafolio-eight-lyart.vercel.app)

---

## 🛠️ Tecnologías Principales

- **Frontend:** React 19, TypeScript, Tailwind CSS, Vite 8
- **3D & Animaciones:** Three.js (WebGL), Framer Motion
- **Mobile & Backend:** Flutter & Dart, Supabase (PostgreSQL), Node.js, Python
- **Audio & Gráficos:** Web Audio API, Canvas 2D
- **Despliegue:** Vercel (Edge CDN global)

---

## ✨ Secciones Destacadas

- **Hero 3D Interactivo:** Núcleo geométrico interactivo renderizado con Three.js y aceleración por GPU.
- **Showreel Motion Graphics:** Animación procedural de 15 segundos sintetizada en tiempo real mediante Canvas y Web Audio API (cero descarga de archivos de video pesados).
- **Proyectos Destacados:** Acordeón dinámico con inspección detallada, demos animadas y métricas de ingeniería.
- **Skills & Ecosistema:** Carrusel modular con arquitectura de componentes desacoplados.
- **Trayectoria Académica:** Formación universitaria en informática, certificaciones internacionales y certificaciones oficiales en IA y Ciberseguridad.

## 🚀 Instalación y Desarrollo Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/ejcb11/mi-portafolio.git
   cd mi-portafolio
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
